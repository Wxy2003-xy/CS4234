An ILP optimizes a linear objective with integer decisions
2
Variables x ∈ ℤⁿ, often binary: xⱼ ∈ {0,1}.
Objective maximize cᵀx  (or minimize cᵀx).
Constraints Ax ≤ b, where every expression is linear.
Integrality models discrete choices—but usually makes optimization hard.

===== PDF PAGE 3 =====
An LP (linear program)relaxation allows fractional decisions
3
ILP
Ax ≤ b
xⱼ ∈ {0,1}
Discrete feasible points
LP relaxation
Ax ≤ b
0 ≤ xⱼ ≤ 1
Continuous feasible region
For maximization: 𝑶𝑷𝑻𝑳𝑷 ≥ 𝑶𝑷𝑻𝑰𝑳𝑷 because the LP has every integer feasible solution plus more (fractional) feasible solutions.

===== PDF PAGE 9 =====
Max-SAT asks us to satisfy as many clauses of a CNFas possible
16
Literal A Boolean variable xⱼ or its negation ¬xⱼ.
Clause An OR of literals, e.g. Cᵢ = x₁ ∨ ¬x₂ ∨ x₄.
CNF An AND of clauses: Φ = C₁ ∧ C₂ ∧ ··· ∧ Cₘ.
Max-SAT Choose an assignment maximizing the satisfied clause weight.
SAT asks whether all clauses can be satisfied; Max-SAT optimizes how many.

===== PDF PAGE 10 =====
Weighted Max-SAT uses clause values
10
Weight Each clause Cᵢ has nonnegative weight wᵢ.
Indicator τ(Cᵢ) = 1 if the assignment satisfies Cᵢ; otherwise 0.
Objective cost(τ) = ∑ᵢ wᵢ τ(Cᵢ).
Goal Choose τ maximizing cost(τ).
Linearity of expectation also works for weighted clauses.

===== PDF PAGE 11 =====
Max-SAT ILP: variables record truth and satisfaction
11
Truth xⱼ ∈ {0,1}: whether Boolean variable xⱼ is true.
Clause yᵢ ∈ {0,1}: whether clause Cᵢ is satisfied.
Objective maximize ∑ᵢ wᵢ yᵢ.
The objective pays for each clause whose satisfaction variable reaches 1.
