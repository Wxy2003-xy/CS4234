Proof for Integrality theorem
Ford-Fulkerson-algo(𝑮,𝒔,𝒕) {
𝒇 𝟎;
While (there is 𝒔-𝒕 path in 𝑮𝒇) do
{   Let 𝑷 be an 𝒔-𝒕 path in 𝑮𝒇
Let 𝒄′be bottleneck capacity of 𝑷;   
For each (𝒙,𝒚) ∈ 𝑷 do
{    If (𝒙,𝒚) is a forward edge then
𝒇(𝒙,𝒚)  𝒇(𝒙,𝒚) + 𝒄′;   
Else
𝒇(𝒚,𝒙)  𝒇(𝒚,𝒙) - 𝒄′; 
}
}  return 𝒇;  
}
Claim:
Ford Fulkerson algorithm computes a maximum 
flow which is integral.
Proof: (By induction on the no. of iteration)
Inductive Assertion: 
At the end of 𝒊th iteration, 𝒇 is integral.
[It is a simple exercise to complete this proof].
In fact, the statement can be shown to hold for 
any flow (not necessary max flow) 𝒇 whose 
value is an integer. 
Hint: In each iteration send only 1 unit of flow 
instead of 𝒄′.

Theorem (part 1): If there is a matching of size 𝒌 in 𝑮 then
there is an 𝒔-𝒕 flow of value 𝒌 in 𝑮′.
Proof: Let 𝑴 be a matching of size 𝒌 in 𝑮. 
We shall construct a flow 𝒇 of value 𝒌 in 𝑮′.
For each edge (𝒙,𝒚) ∈ 𝑴,  where 𝒙 is an applicant and 𝒚 is a job
assign flow of value 1 to the following edges in 𝑮′: (𝒔,𝒙), (𝒙,𝒚), (𝒚,𝒕) 
That is,  𝒇(𝒔,𝒙)  1 , 𝒇(𝒙,𝒚)  1 , 𝒇(𝒚,𝒕) 𝟏
For all remaining edges of 𝑮′assign flow of value 𝟎.
It is easy to verify (do it as an exercise) that conservation constraint as well 
capacity constraints are satisfied by 𝒇. 
Since 𝑴 = 𝒌, it follows from the above construction of 𝒇 that among all edges 
that leave 𝒔, there are exactly 𝒌 edges that carry flow of value 1. 
Hence value(𝒇)= 𝒌. 
This completes the proof of part 1 of the theorem. 50

Theorem (part 2): If there is an 𝒔-𝒕 flow of value 𝒌 in 𝑮′, then
there is a matching of size 𝒌 in 𝑮.
Proof: Let 𝒇 be an 𝒔-𝒕 flow of value 𝒌 in 𝑮′.
We shall now construct a matching of size 𝒌 in 𝑮.
Firstly, by integrality theorem, assume that 𝒇 is integral. 
Consider the set 𝑨= {𝒔} ∪ Applicants
So 𝒇𝒐𝒖𝒕 𝑨 − 𝒇𝒊𝒏(𝑨) = 𝒌
Since there is no edge that enters 𝑨, so 𝒇𝒊𝒏(𝑨) = 𝟎,
Hence 𝒇𝒐𝒖𝒕 𝑨 = 𝒌.
Moreover, since capacity of each edge in 𝑮′is 𝟏, each edge in 𝑮′carries either no flow or a flow of 
value 𝟏. 
Therefore, there are exactly 𝒌 edges between Applicants and jobs that carry flow of value 𝟏. 
Let 𝑴 denote the set of these 𝒌 edges.
Since each edge leaving 𝒔 (and each edge entering 𝒕) has capacity 𝟏, there can be at most one edge 
from 𝑴 incident on any  applicant (or any job).  
It thus follows that the set 𝑴 is indeed a matching in 𝑮. 
This completes the proof of part 2 of the theorem.
