Key points of Ford-Fulkerson algorithm 
that you must fully realize 
• The residual network 𝑮𝒇 is just a tool for manipulating flow in actual network 𝑮.   So
statements like “Sending flow along a path in 𝑮𝒇” DON’T MAKE SENSE.
• The algorithm shuttles back and forth between 𝑮 and 𝑮𝒇 :
- Compute a path in 𝑮𝒇
- manipulate flow in 𝑮 suitably
- Update 𝑮𝒇 accordingly; Compute a path in 𝑮𝒇
- manipulate flow in 𝑮 suitably …. 
• Reducing a flow along an edge in 𝑮 is actually a part of re-distribution exercise which pumps more flow 
from 𝒔 to 𝒕.

Max-Flow Min-Cut Theorem
Theorem: Consider any network 𝑮 = (𝑽, 𝑬) with source 𝒔 and sink 𝒕.
the maximum value of 𝒔-𝒕 flow is equal to the capacity of min-cut.
Question: How to prove this theorem ?
Answer: We shall prove the following:
• Let 𝒇 be the 𝒔-𝒕 flow computed using Ford Fulkerson algorithm (assume it terminates).
• Then there is an 𝒔-𝒕 cut whose capacity is equal to 𝐯𝐚𝐥𝐮𝐞(𝒇).
• Try to realize that if we show this, then we have not only proved correctness of the Ford-
Fulkerson algorithm, but also the max-flow min-cut theorem also.

Ford Fulkerson algorithm
Ford-Fulkerson-algo(𝑮,𝒔,𝒕)
{  𝒇 𝟎;
While (there is 𝒔-𝒕 path in 𝑮𝒇) do
{   Let 𝑷 be an 𝒔-𝒕 path in 𝑮𝒇
Let 𝒄′ be bottleneck capacity of 𝑷;   
For each (𝒙,𝒚) ∈ 𝑷 do
{    If (𝒙,𝒚) is a forward edge then
𝒇(𝒙,𝒚)  𝒇(𝒙,𝒚) + 𝒄′;   
Else
𝒇(𝒚,𝒙)  𝒇(𝒚,𝒙) - 𝒄′; 
}
}  return 𝒇;  
}
