===== PDF PAGE 19 =====
Greedy set cover is logarithmically optimal
19
Algorithm Choose the set with minimum cost per newly covered element.
Guarantee cost(GREEDY) ≤ Hₙ · OPT ≤ (1 + ln n) · OPT.
Limit For every α > 0, (1 − α) ln n approximation is NP-hard. 
[ Dinur & Steurer’14]
A simple local choice achieves an essentially best-possible global guarantee.

===== PDF PAGE 45 =====
Eulerian Cycle
• Definition: In a multigraph 𝐺 = (𝑉, 𝐸), an Eulerian Cycle 𝐶 is a cycle 
(sequence of edges) such that
• Every edge 𝑢, 𝑣 ∈ 𝐸 appears in 𝐶 exactly the same number of times as in 𝐸
(basically, each occurrence of edge 𝑢, 𝑣 ∈ 𝐸 appears exactly once)
45
Eulerian Cycle: A, B, C, D, E, F, G, H, I, J, K

===== PDF PAGE 46 =====
Eulerian Cycle: Existence and Algorithm
• Theorem: A multigraph 𝐺 = 𝑉, 𝐸 has an Eulerian cycle if and only if
• It is connected (except isolated vertices)
• Each vertex has even degree
• Moreover, there is a polynomial time algorithm that, given 𝐺 = 𝑉, 𝐸
finds an Eulerian cycle if exists.
