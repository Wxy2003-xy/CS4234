Problem definition (Informal)
Given a network, where each edge has a certain capacity,
There is a designated source vertex 𝒔 and sink vertex 𝒕.
Compute the maximum flow that we can achieve from  𝒔 to 𝒕.

Question: What is flow along an edge ?
Answer: The rate (per unit time) at which the commodity is being transported along the edge ?
Question: What is capacity of an edge ?
Answer: The maximum rate at which the commodity can be transported along the edge.
Example: 25 litre/sec
